# Matn Memorizer — план реализации

## Объем
Рабочий browser-first MVP для iOS/Android через адаптивный PWA-интерфейс на существующем GitHub Pages без сборщика. Реализуются библиотека матнов, личная коллекция, фрагменты, режимы изучения/скрытия/проверки, Web Speech API, diff ошибок, интервальные повторения, импорт TXT/DOCX/PDF как локального черновика, прогресс, статистика, настройки RTL/русского/темы и локальная админ-форма.

Настоящий аккаунт, облачная синхронизация, Supabase, серверная Arabic ASR, хранение аудио и роли преподавателя требуют отдельного backend-этапа; в интерфейсе они отмечаются как следующий этап, а не выдаются за готовые функции.

## Структура
- `index.html` — адаптивное приложение, стили и клиентская логика.
- `manus-routes.json` — манифест маршрутов.
- `plan.md` — план и дизайн-решения.
- `TODO.md` — трассировка требований и статусы.

## Дизайн
Варианты: «Тихая мадраса» 0.06; «Нефритовый учебник» 0.08; «Черкесская библиотека» 0.03.

Выбран: «Тихая мадраса».
- Design movement: editorial Islamic academic minimalism.
- Core principles: спокойный ритм, уважение к арабскому тексту, одна ясная задача на экран, заметный прогресс без игровой перегрузки.
- Color philosophy: темный нефрит для фокуса и доверия, молочный фон для долгого чтения, матовое золото для этапов и достижений.
- Layout: двухколоночный desktop-shell с узкой rail-навигацией и текстовым reading canvas; на мобильном — нижняя навигация.
- Signature elements: тонкая золотая вертикаль у активного матна, арабские цитаты крупным кеглем, карточки прогресса с мягкими радиусами.
- Interaction: каждое действие дает немедленную обратную связь; сомнительное распознавание отделено от ошибки ученика.
- Animation: короткие 160–220ms transitions, без декоративного движения во время чтения.
- Typography: Inter/system UI для интерфейса, Amiri для арабского текста.
- Brand essence: цифровой помощник طالب العلم для точного заучивания матнов; спокойный, точный, заботливый.
- Voice: «Продолжите с того места, где остановились»; «Проверьте себя без подсказки».
- Wordmark: золотая скобка-мадраса вокруг точки над арабской буквой.
- Signature color: `#0d5c4b`.
