# Аудит Matn Memorizer перед доработкой

## Что уже работает
Существующий проект — статический GitHub Pages single-page app на HTML/CSS/JavaScript без сборщика и backend. Сохранены пять разделов навигации, три встроенных матна, библиотека с поиском и фильтрами, личные матны, локальный импорт текста, просмотр фрагментов, пять уровней скрытия, озвучивание через Speech Synthesis, распознавание через Web Speech API при поддержке браузера, подсветка простого diff, интервальные даты, локальное сохранение прогресса, статистические карточки, RTL/русский режим, темная тема и мобильная навигация.

## Найденные ограничения и ошибки
Алгоритм сравнения сопоставлял слова только по одинаковой позиции и не различал надежно вставку, удаление и перестановку. Харакаты удалялись без возможности отдельного режима. В голосовом режиме не было MediaRecorder-плеера и временных отметок; Web Speech API не является серверным Arabic ASR и зависит от браузера. График профиля содержал фиксированный демонстрационный массив, а не активность пользователя. PWA-манифест и Service Worker отсутствовали. Импорт DOCX/PDF принимал файл, но не извлекал текст; OCR и облачные функции требуют backend/специализированных библиотек.

## Сохраняемые решения
Сохраняются текущая визуальная система, адаптивная структура, арабская типографика Amiri, локальная схема данных и публичный GitHub Pages deployment. Улучшения добавляются обратно совместимо, без удаления существующих кнопок и матнов.

## План ближайшей итерации
1. Заменить позиционный diff на глобальное word-level alignment с нормализацией алифа, хамзы, пунктуации и переключателем огласовок.
2. Перевести график на реальные даты `sessions` пользователя.
3. Добавить MediaRecorder playback и manifest/service worker для PWA.
4. Расширить настройки проверки: буквы, огласовки, порядок, полный текст.
5. Явно обозначить серверные зависимости: Arabic ASR, OCR, Auth, Supabase, синхронизация, преподавательские группы.

## Backend-границы
Нельзя честно реализовать в статическом frontend настоящую серверную Arabic ASR с word timestamps/confidence, аккаунты, облачную синхронизацию, OCR сканов и роли без API/БД. Для этих частей подготовлена архитектурная граница и предупреждения в UI; фиктивное AI-распознавание не добавляется.
